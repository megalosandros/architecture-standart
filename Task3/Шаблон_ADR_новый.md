### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**

| **№**  | **Требование**               |
|:------:|:-----------------------------|
| **R**  | **Надёжность (Reliability)** |
| R01    | Доступность системы подачи заявок (сайт + интернет-банк + Deposits Gateway) — 99,9% круглосуточно | 
| R02    | Поддержка отказоустойчивости: автоматическое переключение на резервный ЦОД при недоступности основного. |
| R03    | Система должна корректно обрабатывать ошибки (например, недоступность СМС-шлюза) без потери данных. |
| **P**  | **Производительность (Performance)** |
| P01    | АБС не должна получать прямые запросы от интернет-банка в реальном времени. |
| P02    | Разделение нагрузки между ЦОДами (активный/активный или активный/резервный). |
| P03    | API получения ставок должен отвечать за ≤ 400 мс в 95% случаев при нагрузке 100 RPS. |
| **+R** | **+Ограничения (Restrictions)** |
| +R01   | Все данные, передаваемые между клиентом и сервером (сайт, интернет-банк), защищаются TLS 1.2+. |
| +R02   | Чувствительные данные (ФИО, телефон) шифруются при хранении, их использование логируется. |
| +R03   | Новые сервисы должны быть совместимы с текущими платформами (C#, Java, MS SQL, Oracle, React). |
